# 汽車駕照筆試通 2026 — 使用手冊

> 給考生與家長的簡單操作說明。網址：**https://tomclin.github.io/taiwan-driving-test-prep/**

---

## 一、安裝（加到主畫面，像 App 一樣用）

1. 用手機瀏覽器開啟上面的網址。
2. **iPhone（Safari）：** 點下方「分享」→ **加入主畫面**。
3. **Android（Chrome）：** 點右上「⋮」→ **加到主畫面／安裝應用程式**。
4. 之後點主畫面圖示即可**全螢幕、可離線**使用，不用每次開瀏覽器。

## 二、首次設定

先到 **更多 → 設定**，填入 **考試日期**（首頁才會顯示倒數天數與每日進度）。可另設每日目標與及格分數（官方約 85 分）。

## 三、首頁（每日儀表板）

一眼看到：**距離考試天數、今日目標、待複習題數、題庫涵蓋率、近期模擬考成績**。完成任何練習或模擬考都會計入今日目標。

## 四、分類練習

- 四大題型：**交通標誌／交通規則／情境防禦／危險感知**；另有「**待複習**」「**錯題練習**」。
- 作答後**立即顯示對錯與解析**；右上角**星號**可把不確定的題標記起來。
- 隨開隨停，適合零碎時間。

## 五、模擬考

- **50 題**、仿新制（含危險感知比例）。
- 作答中**不顯示答案**；可用下方**題號格**快速跳題，星號標記不確定。
- **交卷**後計分（達及格分數即通過），並列出**錯題與標記題**供檢討。

## 六、錯題本（間隔複習，提分關鍵）

- 答錯的題會**自動進錯題本**。
- 依科學間隔重複出現：**當天 → 隔天 → 3 天後 → 7 天後 → 精熟畢業**。
- 點「**開始複習**」做當日到期的題。別跳過複習，這是進步最快的地方。

## 七、搜尋

**更多 → 搜尋題庫**，用關鍵字（如「酒駕」「速限」「標誌」「行人」）找題目、選項或解析。

## 八、家長檢視

**更多 → 家長檢視**：整體涵蓋率、**近 7 天練習量**、各題型正確率、**最需加強的題型**、近期模擬考成績。適合家長掌握趨勢。

## 九、設定與備份（重要）

**更多 → 設定 → 資料管理：**

- **匯出進度**：下載一個備份檔。**換手機、或清除前，先匯出。**
- **匯入進度**：用備份檔還原（進度、成績、設定都會回來，題庫不受影響）。
- **清除作答進度**：兩段式確認；**建議先匯出備份**再清。
- **進階 → 還原內建題庫**：重新載入 1,090 題（例如匯入的題庫有誤時），**不會**清除你的進度。

## 十、資料與隱私

- 所有資料**只存在這台裝置的瀏覽器**，不上傳、免登入、免帳號。
- **換裝置不會自動同步** → 請用「匯出／匯入」搬移進度。
- 想保險，偶爾**匯出一次備份**存起來。

---

## 備考小提醒

- **每天固定做一點**（設好每日目標），比考前臨時抱佛腳有效。
- 善用**錯題本 + 間隔複習**，把錯的變成會的。
- 考前多做幾次**模擬考**抓弱點；家長用**家長檢視**看趨勢。
